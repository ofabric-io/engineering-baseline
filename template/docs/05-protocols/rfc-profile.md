# Standards Profile

## Purpose

Which published standards the project adopts instead of inventing its own, which it deliberately does not, and every known deviation.

## Parameters

| Parameter | Answer | Default | Trade-off |
| --- | --- | --- | --- |
| `adopt_before_invent` | [[adopt_before_invent]] | yes | a local convention only where no standard applies, and recorded here |
| `core_standards` | [[core_standards]] | RFC 2119, RFC 3339, RFC 9562, ISO 8601, ISO 4217 (if money), SemVer, Conventional Commits, OpenTelemetry + W3C Trace Context | packs add their own (e.g. RFC 9457 for http-api) |
